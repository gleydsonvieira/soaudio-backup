Soaudio Backup

Aplicativo interno de cópia de segurança.

O Soaudio Backup é uma ferramenta de uso interno que realiza a cópia de segurança (backup) de arquivos para o Google Drive do próprio proprietário, utilizando o programa de linha de comando rclone.

O aplicativo usa a API do Google Drive apenas para enviar os arquivos de backup para a conta Google do próprio dono do aplicativo. Ele não é oferecido ao público nem processa dados de terceiros.
